# Experiment 2: LSTM-based Vision-Pose Mapping Performance

This folder contains the code and partially available dataset for training and evaluating the **LSTM-based Vision-Pose Mapping (VPM)** model. The experiment evaluates the trajectory prediction performance of the proposed LSTM-based VPM model and compares it with RNN, SVR, and MLP models. An ablation study is also provided to investigate the contribution of different input features.

## Data

The `data` folder contains the multimodal data collected during the acupuncture manipulation experiments.

- `data_hand` — hand keypoint data extracted using MediaPipe, together with the corresponding original video data. The hand representation contains the coordinates of 9 selected hand landmarks.
- `data_pos` — robot end-effector pose and force/torque data recorded during the corresponding manipulation trials.
- Folders `1–4` represent the four acupuncture manipulation types.
- Each manipulation folder contains multiple independent trials.

Due to medical ethics regulations, only a portion of the dataset is currently available on GitHub. The complete dataset contains 10 trials for each manipulation type, while only a subset of the trials is publicly provided.

## Comparative Study

The `comparative_study` folder contains the code for comparing the proposed LSTM-based VPM model with three baseline models: **RNN, SVR, and MLP**.

- `comparative_study.py` — performs the comparative experiments and evaluates the prediction results.
- `tune_hyperparams.py` — performs hyperparameter tuning for the evaluated models.
- `experiment_results.csv` — stores the results generated by the comparative experiments.
- The `.npy` files store the ground-truth trajectories and prediction results used for subsequent visualization.

## Ablation Study

The `ablation_study` folder contains the code for evaluating the contribution of different input features to the VPM model.

- `ablation_study.py` — performs the ablation experiments.
- `ablation_results.csv` — stores the results generated by the ablation experiments and can be directly used for subsequent visualization.

## Visualization

The `plot` folder contains the scripts for generating the figures used in the manuscript.

Place the result files from the comparative and ablation studies in this folder as required by the script, and run:

```bash
python generate_paper_figures.py
```

The script generates the following three figures:

```text
Fig_Trajectory_Comparison.png
Fig_RMSE_Boxplot.png
Fig_Ablation_Barchart.png
```

These figures correspond to the trajectory comparison, RMSE comparison, and ablation study results, respectively.

## Usage

The recommended workflow is:

```text
1. Prepare the available multimodal data
        ↓
2. Train and evaluate the LSTM-based VPM model
        ↓
3. Run the comparative study
        ↓
4. Run the ablation study
        ↓
5. Generate the paper figures
```

The provided code is intended to support the reproducibility of the LSTM-based VPM experiments and the corresponding quantitative analyses reported in the manuscript.
